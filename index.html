Getting Started / 導入編

日本語版 — 導入編

はじめに

KagaLinguaRelay は、Second Life の公開チャットを参加者の言語に合わせて翻訳するリレーです。まずAPIキーを取得し、engine_config を設定してから、各スクリプトを指定のプリムへ入れてください。

1. APIキーを取得する

DeepL

  1. DeepL公式 Quickstart を開き、DeepL API のプランを選んで登録します。
  2. DeepL APIアカウントの API Keys からキーを取得します。
  3. DEEPL_KEY=取得したキー の形式で設定します。Free APIキーは通常 :fx で終わります。

DeepL公式: Access and authentication

Azure Translator

  1. Microsoft公式: Create and configure Azure resources for Translator を開き、Azure Translator リソースを作成します。
  2. リソースの Keys and Endpoint からキーを取得し、作成時に選んだリージョン名を確認します。
  3. AZURE_KEY=取得したキー|リージョン の形式で設定します。例：AZURE_KEY=your-key|japaneast

複数キーを使う場合も、各キーに対応するリージョンを | の後へ記載します。

APIキーの扱い

APIキーは第三者へ共有しないでください。再配布する製品コピーには、必ずキーを削除した engine_config を使用してください。

2. engine_config を作る

  1. 同梱の engine_config sample 2026-07-31 1834.txt をコピーします。
  2. コピーしたノートカードを、正確に engine_config と名前変更します。
  3. 使用するキーの行から先頭の # を削除し、自分のAPIキーへ置き換えます。
  4. ノートカードの権限を、全員・グループはすべてOFF、次の所有者はコピーのみONにします。

3. スクリプトを入れる場所

親プリム 0 ├─ Manager ├─ Que1 ～ Que4 ├─ RateGate └─ DispatchBroker 子プリム 1 ～ 8（各プリム） ├─ Worker └─ Sender

親プリムには上記6種・合計8本のスクリプト、各子プリムには Worker と Sender を1本ずつ入れます。engine_config と必要に応じた ALLOW_LIST は親プリムへ入れます。

4. 起動確認

  1. オブジェクトをリセットします。
  2. オーナーチャットに、選択中エンジンと Active keys が表示されることを確認します。
  3. 翻訳機から20m以内で公開チャットを行い、翻訳を確認します。

赤い ERROR 表示になった場合は、選択中エンジンに有効なキーがありません。engine_config と API Menu のキー状態を確認してからリセットしてください。

English Edition — Getting Started

Before You Start

KagaLinguaRelay translates Second Life public chat according to each participant's language. Obtain API keys, configure engine_config, then place the scripts in the designated prims.

1. Obtain API Keys

DeepL

  1. Open the official DeepL Quickstart, choose a DeepL API plan, and sign up.
  2. Get a key from the API Keys area of your DeepL API account.
  3. Add it as DEEPL_KEY=your-key. Free API keys normally end in :fx.

DeepL: Access and authentication

Azure Translator

  1. Open Microsoft's Translator resource guide and create an Azure Translator resource.
  2. On the resource's Keys and Endpoint page, copy a key and note the region selected when creating the resource.
  3. Add it as AZURE_KEY=your-key|region; for example, AZURE_KEY=your-key|japaneast.

With multiple keys, write the matching region after every key, following |.

Protect API Keys

Do not share API keys with third parties. Before redistributing a product copy, remove keys from engine_config.

2. Create engine_config

  1. Copy the included engine_config sample 2026-07-31 1834.txt.
  2. Rename the copy exactly engine_config.
  3. Remove the leading # from lines you will use and replace the example values with your own keys.
  4. Set notecard permissions: Everyone and Group none; Next owner Copy only.

3. Script Placement

Root prim 0 ├─ Manager ├─ Que1 through Que4 ├─ RateGate └─ DispatchBroker Child prims 1 through 8 (each prim) ├─ Worker └─ Sender

Place the eight scripts listed for the root prim into the root. Put one Worker and one Sender into every child prim. Put engine_config, and optionally ALLOW_LIST, into the root prim.

4. Verify Startup

  1. Reset the object.
  2. In owner chat, confirm the selected engine and Active keys count.
  3. Use public chat within 20 metres of the relay and confirm translation.

If a red ERROR display appears, the selected engine has no usable key. Check engine_config and the API Menu key state, then reset.
