コードの読み方

通常の表示とメインメニューは、Engineから返った上位3桁のHTTPステータスを使います。たとえばAzureの 403001 は、メニューでは Other Errors [403] として扱われます。6桁の詳細コードは、HTTP本文の先頭50文字に含まれる場合だけ確認できます。598 はEngine由来ではなく、応答切断またはHTTP 200本文の解析不能を示す翻訳機内部コードです。

1. 翻訳停止・キー関連

状態通知・自動処理対処
利用可能なAPIキーが0件【SSJ Translation Relay：翻訳停止警告】
赤いERRORホバーテキストを固定表示します（点滅しません）。		Owner Manualの engine_config 設定を確認し、キーを追加・修正してからResetします。
赤いERROR表示選択中エンジンに有効なキーが0件です。赤いERRORホバーテキストは固定表示で、点滅しません。Engine選択、API MenuのON/OFF、キー設定を確認し、修正後にResetします。

2. DeepL API 応答コード

DeepL公式: Error handling ／ DeepL公式: Translate text API reference

HTTPコード主な意味翻訳機の処理と対処
400要求の内容、言語コード、またはパラメーターが不正です。DeepLで発言元言語指定が原因の場合だけ、発言元言語を指定しない形で1回再試行します。繰り返す場合は言語設定、特殊文字、キーを確認します。
401 / 403認証・権限・キー種別・契約状態の問題です。該当キーを自動OFFにします。キー、DeepL APIの契約・権限、FreeキーとProキーの種別を確認し、修正後にResetします。
413 / 415 / その他の4xx要求サイズまたは要求形式の問題などです。翻訳機は長文を事前分割します。繰り返す場合は本文を短くし、オーナーチャットの本文先頭50文字と公式ページを確認します。
429短時間に送信しすぎたリクエスト制限です。該当キーだけ1→2→4…秒、最大30秒まで待機します。失敗した1文は再送せず、後続処理を続けます。頻発時だけ連投を減らすかキーを増やします。
456DeepLの利用枠またはCost Control上限に達しました。456 Quota Limitを加算し、該当キーを自動OFFにします。利用枠・Cost Controlを確認するか、キーを追加・交換してResetします。
500 / 503 / その他の5xxDeepLまたは経路の一時的なサービス障害です。Other Errors [コード]を加算し、現在の文を終了して後続処理を続けます。少し待ち、継続する場合は公式ステータスとHTTP本文を確認します。

DeepL公式がエラー処理として明示している代表値は429、456、500です。ほかのHTTPコードが返った場合も、翻訳機は受信した上位HTTPコードをそのまま表示します。

400
400050, 400072, 400074, 400077		本文が長すぎる、要素数超過、JSON形式不正、要求サイズ超過です。長文は事前分割されます。繰り返す場合は本文を短くし、HTTP本文の詳細コードを確認します。

401000, 401015		キーが無効、またはTranslator Text APIではない資格情報です。該当キーを自動OFFにします。Translator用キーと、そのキーのリージョンを確認します。
403
403000, 403001		操作が許可されない、または試用枠を使い切りました。該当キーを自動OFFにします。契約・利用枠・キーとリージョンを確認します。Azureの利用枠超過は通常456ではなく403系で返ります。

405000, 415000		HTTPメソッドまたはContent-Typeが不正です。翻訳機側の要求形式を示すため、繰り返す場合はWorker番号とHTTP本文を添えて報告してください。

429
429000, 429001, 429002		リクエスト制限です。該当キーだけ1→2→4…秒、最大30秒まで待機します。頻発時だけ連投を減らすかキーを増やします。
500 / 503
500000, 503000		Azureサービス側の一時的な内部エラーまたは停止です。現在の文を終了して後続処理を続けます。少し待ち、継続する場合はHTTP本文と時刻を記録して確認します。

4. 翻訳機内部コード 598

598 はDeepL／AzureのHTTPコードではありません。応答本文が途中で切れた、またはHTTP 200でも翻訳本文を完全に解析できなかったことを表します。翻訳機はより小さな分割で自動再試行し、最後まで取得できない場合だけ ...[Character limit] を付けて後続処理を続けます。通常は対処不要です。頻発する場合だけ文章を短くしてください。

How to Read the Codes

Ordinary output and the main menu use the three-digit top-level HTTP status returned by the engine. For example, Azure detail code 403001 is handled in the menu as Other Errors [403]. A six-digit detail code can be seen only when it appears within the first 50 response characters. 598 is a relay-internal code, not an engine code; it means a truncated response or an unparseable HTTP 200 body.

1. Translation Stopped and Keys

ConditionNotice and automatic actionWhat to do
No usable API key[SSJ Translation Relay: Translation Stopped]
A red ERROR hover text is shown continuously; it does not blink.		Check the engine_config setup in the Owner Manual, correct or add keys, then Reset.
Red ERROR displayThe selected engine has no active key. The red ERROR hover text is static, not blinking.Check Engine selection, API Menu ON/OFF state, and the key configuration; then Reset.

2. DeepL API Response Codes

DeepL official: Error handling ／ DeepL official: Translate text API reference

HTTP codeMain meaningRelay handling and action
400The request, language code, or parameter is invalid.Only for a DeepL source-language failure, the relay retries once without the source language. If repeated, check language settings, unusual text, and the key.
401 / 403Authentication, permission, key type, or subscription state issue.The affected key is disabled automatically. Check the key, DeepL API subscription/permission, and whether it is a Free or Pro key; then Reset after correction.
413 / 415 / other 4xxFor example, request size or request format issue.The relay pre-splits long text. If repeated, shorten the text and check the first 50 response characters and official documentation.
429Too many requests in a short period.Only that key backs off by 1→2→4… seconds, up to 30 seconds. The failed message is not resent; later work continues. If frequent, reduce bursts or add keys.
456DeepL quota or Cost Control limit reached.456 Quota Limit increases and the affected key is disabled. Check quota/Cost Control, or add/replace a key and Reset.
500 / 503 / other 5xxTemporary DeepL or network-path service failure.Other Errors [code] increases. The current message ends and later work continues. Wait briefly; if persistent, check the official status and response text.

DeepL's central error-handling page explicitly documents 429, 456, and 500. If another HTTP code is returned, the relay displays the received top-level code unchanged.

3. Azure Translator API Response Codes

Azure official: Response codes and messages ／ Azure official: Translate method

HTTP / detail codeMain meaningRelay handling and action
400
400000, 400003, 400005, 400019, 400023, 400035, 400036		Invalid input, language, language pair, source, or target specification.Other Errors [400] appears and the current message ends. Check target language, text, and the Azure key/region pair.
400
400050, 400072, 400074, 400077		Text too long, too many elements, invalid JSON, or maximum request size exceeded.Long text is pre-split. If repeated, shorten the message and check the detail code in the response text.
401
401000, 401015		Invalid key, or credentials are not for the Translator Text API.The affected key is disabled automatically. Check the Translator key and its region.
403
403000, 403001		Operation not allowed, or trial quota exhausted.The affected key is disabled automatically. Check subscription, quota, key, and region. Azure quota exhaustion normally returns a 403-series code, not 456.
405 / 415
405000, 415000		Invalid HTTP method or Content-Type.This concerns request format. If it repeats, report the Worker number and response text.
408
408001, 408002		Translation system is preparing, or the request timed out waiting for input.This is temporary. Wait briefly and send the message again.
429
429000, 429001, 429002		Request-rate limit.Only that key backs off by 1→2→4… seconds, up to 30 seconds. If frequent, reduce bursts or add keys.
500 / 503
500000, 503000		Temporary Azure internal error or service unavailability.The current message ends and later work continues. Wait briefly; if persistent, keep the response text and time for investigation.

4. Relay-Internal Code 598

598 is not a DeepL or Azure HTTP code. It means the response body was truncated or that the translated text could not be fully parsed even with HTTP 200. The relay retries in smaller pieces; only the final unrecoverable part ends with ...[Character limit], allowing later work to continue. Normally no action is needed. Shorten messages only if it becomes frequent.
