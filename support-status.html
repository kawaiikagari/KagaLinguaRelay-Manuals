English Edition — Support Status
Supports 35 languages (37 variants including regional and writing-system differences).
The table lists languages that this relay handles as DeepL or Azure translation targets. Simplified and Traditional Chinese, and Brazilian and European Portuguese, are listed separately, giving 37 entries.
The selected API automatically detects the source language from the message content. The translation target is the recipient's viewer language setting. Both DeepL and Azure fall back to English if that setting is unavailable or its language code is unsupported by the relay.
Note: The count is based on the translation-target language codes implemented in this relay. This is not a direct list of every language supported by each API provider.
