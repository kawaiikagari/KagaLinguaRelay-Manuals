Owner Manual

日本語版 — オーナーマニュアル

概要

近くにいるアバターの公開チャットを、宛先のビューア言語に合わせて翻訳します。DeepL または Azure を選択でき、翻訳文は距離条件を満たす宛先本人のチャット欄だけに表示されます。技術的には、llRegionSayTo による宛先指定のチャンネル0チャットです。Rez時とHUD装着時は同じ翻訳ルールで動作します。

1. 設置・基本動作

  • 翻訳対象は翻訳機から20m以内にいるアバターです。範囲外へ移動したアバターには翻訳結果を送りません。
  • 発言者と同じ言語の宛先には翻訳を送りません。
  • 同じ宛先言語のアバターが複数いる場合も、翻訳リクエストは言語ごとに1回だけ行い、結果を各宛先へ配信します。
  • 宛先のビューア言語を取得できない場合だけ、その宛先は英語へフォールバックします。発言者の言語を取得できない場合は、選択中APIの自動判定を利用します。
  • HUDとして装着した場合も、Rez時と同じ翻訳・距離判定・宛先ごとの配信で動作します。装着中はHUDをタッチしてオーナーメニューを開きます。

URLを含む発言

発言中のhttpから次の空白、タブ、改行または全角空白までの部分は、DeepL／Azureへ送る前に文中の(URL removed)へ置き換えます。文末への追加ではありません。

2. engine_config の設定

ノートカード engine_config にAPIキーを記載します。同じ種類のキーは複数行登録でき、DeepLとAzureのキーは同じノートカードに併記できます。

DEEPL_KEY=your-deepl-key DEEPL_KEY=another-deepl-key # Azure: key and resource region are a pair. AZURE_KEY=your-azure-key|japaneast AZURE_KEY=another-azure-key|eastus

Azureでは、各キーの末尾に |リージョン を記載します。異なるAzureリージョンのキーを同じ翻訳機に混在できます。使用するエンジンはオーナーメニューの Engine から選択します。

旧式のAzure設定

同じリージョンのAzureキーだけを使う場合は従来形式も使えます。この形式の REGION= は、キーごとの |リージョン を書かないキーだけの共通リージョンです。

AZURE_KEY=legacy-azure-key AZURE_KEY=another-legacy-azure-key REGION=japaneast

4. 長文・連続送信

短い発言ほど速く安定します。長文は安全な長さで自動分割され、結果が複数回に分けて届く場合があります。HTTP応答が途中で切れた場合は、より小さな単位で再試行します。それでも完全な結果を取得できない場合だけ、最後の部分に ...[Character limit] を付けて後続処理を継続します。

同一APIキーへの送信は全Workerで共有して0.5秒以上の間隔で制御されます。429時は該当キーだけ1→2→4…秒（最大30秒）の待機を適用します。失敗した1文は再送せず、次の処理を継続します。

5. 表示・通知とエラー

ホバーテキストにはPower、Mode、Engine、Active Keys、Workersだけを表示します。429／456／Other Errorsはメインメニューだけに表示されます。通常のHTTPエラーはオーナーチャットに表示されます。翻訳停止時だけ、オーナーへ日英併記の警告IMを1回送信します。

表示意味・対応
429 Rate LimitAPIのリクエスト制限です。連投を控え、少し待ってください。
456 Quota Limitキーの利用枠です。該当キーはOFFになります。キーを交換または追加してリセットしてください。
Other Errors [番号]その他のHTTPエラーです。番号、選択中のエンジン、キー、Azureのキーとリージョンの組合せを確認してください。
赤色のERROR表示利用可能な翻訳経路がない状態だけに表示されます。設定を直してリセットしてください。

エンジン別のHTTPコード、通知文、対処は エラーコードと通知 をご覧ください。

6. Second Lifeスクリプト実行エラー

Stack-Heap Collision はDeepL／Azureの応答コードではなく、Second Lifeがスクリプトの実行メモリ不足を検出したランタイムエラーです。発生時はオブジェクトをResetし、直前の発言・選択Engine・表示されたWorker番号を記録してください。長文が原因と疑われる場合は、短くして再確認します。再発時はその記録を添えて報告してください。

7. 外部翻訳サービスについて

DeepLおよびAzure Translatorは外部サービスです。APIの料金・無料枠・利用上限・対応言語・仕様・提供状況は各提供元により変更または終了されることがあります。その変更または障害により、翻訳が利用できなくなる場合があります。

本製品にはAPIキー、翻訳利用枠、または外部サービス料金は含まれません。利用者自身のアカウント、APIキー、利用料金および各サービスの利用規約の管理が必要です。

製品の不具合は可能な範囲で対応を検討しますが、外部サービスの変更・停止に対する継続動作または更新を保証するものではありません。

8. 対応言語

English Edition — Owner Manual

Overview

The relay translates nearby public chat into each recipient's viewer language. Choose DeepL or Azure; translations appear only in the chat window of each recipient that meets the range condition. Technically, this is a recipient-targeted channel-0 chat sent with llRegionSayTo. Rezzed and HUD-attached operation use the same translation rules.

1. Setup and Basic Operation

  • Only avatars within 20 metres of the relay are targets. No result is sent outside that range.
  • Recipients using the same language as the speaker do not receive a translation.
  • One request is made for each target language, even when several recipients use that language; the result is delivered to each eligible recipient.
  • Only recipients whose viewer language cannot be obtained fall back to English. If the speaker language cannot be obtained, the selected API detects it automatically.
  • HUD-attached operation uses the same translation, range, and per-recipient delivery rules as rezzed operation. Touch the attached HUD to open the owner menu.

Messages Containing URLs

Before sending text to DeepL or Azure, the part from http through the next space, tab, newline, or full-width space is replaced inline with (URL removed). This is not an end-of-message annotation.

2. Configuring engine_config

Put API keys in the engine_config notecard. Multiple keys of either type may be listed, and DeepL and Azure keys can share the same notecard.

DEEPL_KEY=your-deepl-key DEEPL_KEY=another-deepl-key # Azure: key and resource region are a pair. AZURE_KEY=your-azure-key|japaneast AZURE_KEY=another-azure-key|eastus

For Azure, append |region to every key. Keys from different Azure regions may be mixed. Choose the active engine from Engine in the owner menu.

Legacy Azure Format

When every Azure key uses one region, the older format remains available. In this format, REGION= is the shared region only for Azure keys without |region.

AZURE_KEY=legacy-azure-key AZURE_KEY=another-legacy-azure-key REGION=japaneast

4. Long Messages and Bursts

Short messages are faster and more reliable. Long messages are split into safe pieces and may arrive in several parts. An incomplete HTTP response is retried in smaller pieces; only when it still cannot be completed does the final part end with ...[Character limit], allowing later work to continue.

Requests sharing one API key are spaced by at least 0.5 seconds across all Workers. A 429 backs off only that key by 1→2→4… seconds, up to 30 seconds. The failed message itself is not resent; later work continues.

5. Display, Notices, and Errors

Hover text shows only Power, Mode, Engine, Active Keys, and Workers. 429, 456, and Other Errors appear only in the main menu. Ordinary HTTP errors appear in owner chat. Only a translation-stopped condition sends one bilingual warning IM to the owner.

DisplayMeaning and action
429 Rate LimitAPI request limit. Reduce bursts and wait briefly.
456 Quota LimitKey quota. The affected key is disabled; replace or add a key, then reset.
Other Errors [code]Another HTTP error. Check the code, selected engine, key, and Azure key/region pair.
Red ERROR displayShown only when no usable translation route remains. Correct configuration and reset.

For engine-specific HTTP codes, notice text, and actions, see Error Codes and Notices.

6. Second Life Script Runtime Errors

Stack-Heap Collision is not a DeepL or Azure response code. It is a Second Life script-runtime memory error. If it occurs, Reset the object and record the preceding message, selected Engine, and displayed Worker number. If long text may be involved, retry with shorter text. Include those details when reporting a recurrence.
