Azure Translator F0 参考情報

本資料は、KagaLinguaRelay (Translation Relay Sysytem) で Azure Translator（トライアル終了後）を利用するための参考情報です。翻訳機の保証対象外です。

Azure Translator の最安構成

Azure Translator の標準テキスト翻訳を最も低い料金で利用する設定は、Azure AI Translator の F0（Free）価格レベルです。

F0 を維持し、S1 などの有料価格レベルへ変更しないことが重要です。

F0 の料金ページに記載されている無料枠は月間 200 万文字です。 Azure Translator の料金

Azure アカウントの登録

標準の Azure 無料アカウント登録には、電話番号、Microsoft アカウントまたは GitHub アカウント、およびプリペイドではない支払いカードが必要です。Microsoft は支払いカードとしてクレジットカードまたはデビットカードを案内しています。対応カードは国・地域によって異なります。 Azure 無料アカウント公式 FAQ

Azure 無料トライアルの終了後も Azure を利用し続けるには、従量課金制への移行が必要です。移行しない場合、アカウントとサービスは無効になります。 Azure 無料アカウント公式 FAQ

Azure Portal での作成

  1. Azure Portal で「リソースの作成」を選ぶ。
  2. Translator を検索し、Azure Translator リソースを選ぶ。
  3. 価格レベルで F0（Free）を選ぶ。
  4. リソース作成後、「Keys and Endpoint」から接続に必要な情報を取得する。

F0 の翻訳リソースは、Azure サブスクリプションごとに 1 つです。

Azure Translator F0 Reference Information

This document provides reference information for using Azure Translator after the free trial period with KagaLinguaRelay (Translation Relay Sysytem). It is outside the translator’s warranty coverage.

Lowest-Cost Azure Translator Setup

The lowest-cost configuration for Azure Translator standard text translation is the Azure AI Translator F0 (Free) pricing tier.

It is important to keep the pricing tier on F0 and not change it to S1 or another paid tier.

The F0 pricing page lists a free allowance of 2 million characters per month. Azure Translator pricing

Azure Account Registration

A standard Azure free account requires a phone number, a Microsoft account or GitHub account, and a non-prepaid payment card. Microsoft lists credit cards and debit cards as accepted payment methods; available cards vary by country or region. Azure free account FAQ

To continue using Azure after the Azure free trial ends, the account must be moved to pay-as-you-go. Otherwise, the account and services are disabled. Azure free account FAQ

Creating the Resource in Azure Portal

  1. In Azure Portal, select Create a resource.
  2. Search for Translator and select the Azure Translator resource.
  3. Select F0 (Free) as the pricing tier.
  4. After deployment, obtain the required connection details from Keys and Endpoint.

Only one F0 Translator resource is available per Azure subscription.
